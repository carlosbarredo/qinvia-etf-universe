# Contributing

Issues and focused pull requests are welcome, especially for reproducibility, identity resolution, taxonomy evidence and statistical limitations.

Before proposing a change:

1. install the development environment with `python -m pip install -e ".[dev,research]"`;
2. run `python -m pytest`;
3. preserve the distinction between product identity, economic eligibility and performance;
4. do not commit raw third-party price histories, credentials or local runtime files;
5. document any change that alters the cohort, cash convention, benchmark alignment or reported counts.

Quantitative conclusions must follow from regenerated evidence. Editorial changes must not silently alter formulas, dates, assumptions or results.
