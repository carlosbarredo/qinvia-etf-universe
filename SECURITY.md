# Security

Please do not open a public issue for a suspected vulnerability that could expose credentials, local paths or unpublished data. Report it privately to the repository owner through the contact route published at [qinvia.com](https://qinvia.com/).

This research project downloads public market data and writes local caches. It does not require trading credentials, brokerage access or private API keys. Any future integration that introduces authenticated execution must remain outside this repository unless it has a separate security review.
